Terminal cheatsheet (WezTerm, native panes)

Core:
  Cmd+d            Split current pane left/right
  Cmd+Shift+d      Split current pane top/bottom
  Cmd+w            Close current pane
  Alt+Arrows       Move between panes
  Cmd+Alt+Arrows   Resize current pane
  Cmd+Enter        Zoom / unzoom current pane

Tabs:
  Cmd+Shift+w      Close current tab
  Cmd+t            New tab
  Cmd+Shift+{/}    Previous/next tab
  Cmd+Shift+,      Rename tab

Copy / search:
  Cmd+c            Copy selection
  Cmd+v            Paste
  Cmd+f            Search scrollback
  Cmd+Shift+x      Copy mode
  Cmd+Shift+o      Quick-open URL from the screen

Shell editing:
  Cmd+Left/Right   Move to beginning/end of line
  Opt+b / Opt+f    Move by word
  Opt+Backspace    Delete previous word
  Opt+d            Delete next word
  Shift+Enter      Insert newline without running the command

Window / app:
  Cmd+Shift+h      Open this cheatsheet
  Cmd+Shift+r      Reload WezTerm config
  Ctrl+Cmd+f       Toggle fullscreen
  Cmd+Shift+0      Restore normal window level
  Cmd+Shift+Up     Always on top
  Cmd+Shift+Down   Always on bottom

dev-tabs behavior:
  `dev-tabs` opens a native WezTerm layout instead of attaching to tmux.
  `dev-tabs --reuse-tab` reuses the current WezTerm tab when run inside WezTerm.
  `dev-tabs --new-tab` opens a fresh tab in the current WezTerm window, or a new
  window when run outside WezTerm.
